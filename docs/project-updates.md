# Project health updates

Any active workspace member can publish a short Markdown update with On track, At risk or Off track health, including the first post on a project without a lead. The latest non-withdrawn post is the project health summary. History is shown newest first by publication date; editing an older post does not promote it.

Authors and Admins may edit or withdraw a post. Every published/edit/withdrawal version is retained in revision history, including its text, health, actor and date. Withdrawal leaves a visible historical record rather than destroying its content. Other members can read history but cannot change someone else's post. Archived projects are read-only.

Optimistic version checks reject stale changes and preserve draft text. A user must explicitly choose to keep their draft against the latest version before retrying. Safe Markdown uses the existing renderer. Health notes do not alter computed issue/estimate progress. This release has no update reminders or external delivery.
